The State of the Theory Framework for Agentic Systems

A first note on what a useful theory of agentic systems should try to preserve, and why many clean mathematical abstractions miss the parts that matter most in practice.

Last updated: June 23, 2026

It is very easy to mathematize things. It is much harder to build mathematical models that are actually useful. In this context, useful means something more demanding than elegance or tractability: it means the model minimally captures what matters practically. That is the standard I care about for agentic systems. Otherwise one risks building a theory of a shadow object — something mathematically crisp, internally coherent, and only weakly connected to the systems that people are actually deploying and studying.

This is especially tempting for agentic systems because they seem to invite abstraction. There are loops, planners, verifiers, critics, memory modules, tool calls, and multi-agent decompositions, so it is easy to start drawing diagrams and assigning symbols. But not every decomposition deserves a theory. A useful framework should preserve the practical asymmetries: where the verification signal comes from, which substeps are actually reliable, which components are only heuristically helpful, where selection errors accumulate, and what kind of object is being produced in the end. Without those ingredients, the mathematics may describe an architecture class while saying very little about why some systems work and others fail.

What a useful framework should preserve

  • The difference between proposal, critique, comparison, verification, and execution.
  • The kind of artifact being produced: text, code, proof sketch, experimental plan, manuscript, patch.
  • Whether the system has access to local soundness signals or only weak heuristic preferences.
  • Where the useful diversity actually comes from, and where more branching only adds noise.
  • What the human is still doing that the formalism might be silently outsourcing.
My current bias is that the right theory framework for agentic systems should look less like a generic control loop and more like a structured map of information, verification, and error composition.
